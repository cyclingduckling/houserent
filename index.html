  1. 가운데 하늘색 박스 안의 작은 파란 글씨 creating a new file 클릭
  2. 상단 Name your file... 칸에 index.html 입력 후, 아래 넓은 칸(`Enter file contents here`)에 복사한 코드를 붙여넣기(Ctrl+V)
